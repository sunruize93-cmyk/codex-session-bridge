微信不支持 Windows/Linux。当前 native 实现只处理显式可访问 AX 控件，不截图、不 OCR、不遍历历史、不注入协议或提取数据库密钥。搜索候选不唯一、编辑器/发送按钮不可访问时失败。已支持参考实现的 Search/AXTextArea 控件，但真实版本和中文布局仍待权限后验证。

微信账号标识（current_account_id/wechat_account_id）、稳定接收者标识（current_chat_id）、消息 ID 与 outgoing 元数据必须由实际 AX 提供。当前客户端是否提供这些信息尚未知；这些分支仅做了合成契约测试。缺少稳定账号或接收者证据时禁止发送；不要把给予权限视为已经解决此限制。无稳定接收者的只读结果带部分结果语义；同名候选仍拒绝自动选择。

小红书经典 DOM、搜索路由 keyword、新结果变化和有限可见内容由固定程序检查。AI 搜索布局、创作中心账号选择器、发布成功标识没有实机快照支持，布局不符合时返回 UI_CHANGED。第一版不保证这些布局可用。主站账号与创作中心账号分别核对，无法读出一致身份时拒绝写入。

结果核对只读取本次点击内捕获的专属回执（含新稳定 ID、同目标/作者/正文），没有回执时不能靠准备快照或旧同文内容推断成功。缺少稳定标识时保留 OUTCOME_UNKNOWN，绝不把旧同文消息或按钮点击当成功；仅可确认界面结果，不能证明微信送达或已读。
