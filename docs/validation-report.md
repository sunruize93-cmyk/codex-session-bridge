## 已完成代码与本地验证

- 18 个有界 schema 的 MCP 工具、初始化中文说明、工具读写/幂等元信息。
- SQLite 持久化、请求幂等、原子提交边界、默认禁写与 trusted-host 范围约束。未知结果不重发。
- OS flock、私有 Unix socket、全局前台串行、人工暂停、取消、恢复、后台短任务查询。
- 浏览器固定 profile/session/page；站内搜索、当前结果/笔记有限读取、图文和评论草稿、条件提交与回执。
- 微信原生 AX 工作者：唯一聊天定位、有限读取、文字草稿；稳定账号/接收者证据不足时拒绝发送。
- 32 项 TypeScript/真实本地 MCP/IPC 测试通过，13 项 Python AX 合成测试通过。另覆盖新版搜索、误点 AI 回退、重复笔记链接、路由先于正文挂载、点赞噪声、安全重登模态层、消息登录按钮误报及 doctor 零应用 AX 探测。
- 类型检查、构建、格式检查和 npm audit（0 漏洞）通过。node:sqlite 为实验性 API，提示仅在 stderr。
- 两名独立代理分别攻击核心与适配器，并做修复复核；后续发现已补回归。详见 review-report.md。无真实账号安全测试或验证触发压力测试。

- `codex mcp add` 和 `codex mcp get` 确认注册到实际绝对 Node/构建文件路径。
