## 代码与合成验证

- 20 个有界 schema 的 MCP 工具，新增 `ig_search`、`ig_read_post`；Instagram 没有写入工具，prepare/dispatch/reconcile 也在 transport 前拒绝。
- 默认 doctor 仅浏览器；显式 `channel:instagram_web` 只查该适配器。微信必须明确选择 `wechat_macos` 才启动其诊断；本轮未调用。
- 版本化 IPC 封套先于业务分发校验；旧协调器会拒绝保留工具名，新客户端不会回退旧协议或自动杀旧进程。
- 53 项 TypeScript / DOM / 真实本地 MCP / fake Unix socket 测试；25 项 Python 合成测试。覆盖固定渠道、来源、绑定释放、账号切换、正文归属、隐藏内容、旧结果、限流文案误报、未知只读导航不重放及微信零调用。
- 类型检查、构建、格式检查和依赖审计另行执行；node:sqlite 的实验性提示仅写 stderr。
- 两名独立代理做离线对抗审查、最小反例与修复复核；不访问用户账号。详见 [review-report.md](review-report.md)。合成测试通过不等于所有平台页面通过。

## 安装与分发

源码构建、插件 marketplace 安装、缓存 MCP 工具发现、隔离安装包自检分开验证。运行包提供构建 JS、生产 node_modules、Python 锁与 macOS wheelhouse、官方扩展 ZIP。浏览器功能只需 Node、Python 3（系统锁）、Chrome 和扩展；微信额外依赖不是浏览器功能的前置步骤。

运行包作为私有草稿发行附件；GitHub 只存代码、合成样本和脱敏报告。原始执行输出、账号状态与实际正文不进入 Git。安装、Cookie 和平台登录是否正常仍以用户实际窗口为准，manifest 或 tools/list 不代表业务验收。
