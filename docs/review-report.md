# 对抗式审查与修复

2026-10-22。两名独立审查代理，分别攻击协调状态机与平台适配器；主实现者修复并补充回归测试。代理输出是本项目审查证据，不是平台认证。

| 发现                                  | 修复                                        | 验证                           |
| ------------------------------------- | ------------------------------------------- | ------------------------------ |
| 重复 bind 在拒绝前已触碰后端          | 先检查现有绑定                              | mock 计数保持一次              |
| 排队后关闭写入仍发送                  | DISPATCHING 前重新检查开关与 scope          | dispatch 次数为零              |
| recover 解除人工暂停                  | 保留 PAUSED                                 | 重启后前台仍冻结               |
| 提交遇验证仅记录未知，不冻结          | 未知结果与暂停同时保留                      | 下一任务不执行                 |
| 取消终态抹去成功                      | 终态取消幂等                                | SUCCEEDED 保持                 |
| 页面异常被上游映射成 UI_CHANGED       | 固定程序返回结构化错误                      | 登录墙与验证码测试             |
| 旧搜索卡片被当作新结果                | 同时检查路由查询、输入值、卡片变化          | 旧卡片不返回；合成样本         |
| 同数量图片替换仍可发布                | 记录预览身份/顺序与本地文件摘要，提交重核   | 图片替换回归                   |
| 微信同名对象引用碰撞                  | 有稳定接收者时纳入 chat_ref；缺失则禁止发送 | 同名不同 recipient 拒绝        |
| kill 后未确认旧 worker 已退出便释放锁 | 等待 child close 后返回                     | 单次工作者生命周期代码审查     |
| 核对固定返回否定                      | 捕获本次点击的专属回执；缺失则保留未知      | 无点击回执的旧同文内容不确认   |
| AX 搜索排除已知控件                   | 加入 AXTextArea + title Search              | 源码契约核对；真实未验         |
| 七天保留声明不准确                    | 终态七天；未决保留至显式忘记正文            | 文档与 forget-payload 保留账本 |

复核新增修复：异步哈希后同步重查账号/遮罩；prepare 快照不再作为结果确认依据，改为提交调用内捕获专属回执；取消与恢复交叉时保留取消；重复未知恢复不增加代次；忘记正文使用事务与删除墓碑，旧内存对象不得恢复正文。上述路径均补回归。

剩余风险：真实平台 DOM、AX 和账号身份可观测性；固定版本升级需重新验证；本地用户进程属于信任边界；本地去重不等于平台端 exactly-once。详见 compatibility.md 与 validation-report.md。
